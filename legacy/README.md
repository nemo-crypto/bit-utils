# 历史实现对照区

这里保存重构前的源码、手工示例、构建配置及发布脚本，用于对照学习，不参与当前安装、构建、测试或 CI。

历史基线提交：`395602b393571f3b17092a348b7fd0d423cfca59`。原来的生成文件 `dist/` 可从此提交查看，不作为教学源码保留。

旧实现的问题包括缺失的 postinstall.js、吞掉异常的构建脚本、混杂的 Rollup/Babel 插件、依赖浏览器全局的缓存类，以及没有统一自动化测试。请先阅读新主线，再选择性对照旧实现。

该目录不是可独立运行的包；内部路径仍反映原项目布局。不要在这里安装依赖或运行 release/publish 脚本，历史脚本可能提交、打标签、推送或发布。发布流程原文见 `../docs/original-release-notes.md`。

新主线是 private 教学 Demo，公共 API 已精简，不是旧 bi-utils 的兼容升级。旧 API 的使用方应保留原版本，按实际需求迁移，不能直接替换依赖。
